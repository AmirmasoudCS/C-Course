19. [Session 19 - Mini Project: Digital Clock](./Session_19/)

## Topics Covered

* C syntax and basic program structure
* Variables and data types
* Format specifiers
* Operators
* User input
* Arrays and 2D arrays
* Functions
* Ternary operators
* `typedef`, `enum`, and `struct`
* Pointers
* File I/O
* Dynamic memory allocation
* `malloc()`, `calloc()`, and `realloc()`
* Small practical C projects
